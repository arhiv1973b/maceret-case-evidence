### О проекте

Это цифровой архив доказательств для международного правосудия. Архив документирует системные нарушения jus cogens (императивных норм международного права) в деле Case Maceret (1997-2026).

### Правовая квалификация

- **Jus Cogens**: Запрет пыток является императивной нормой (ст. 53 Венской конвенции 1969)
- **Erga Omnes**: Обязательства перед международным сообществом
- **Статья 64 ВК69**: Возникновение новых императивных норм аннулирует противоречащие договоры
- **Статья 17 Римского статута**: Принцип комплементарности МУС

### Jus Cogens Violations

Императивные нормы не имеют срока давности. Каждое нарушение фиксируется во времени:

```
Norm(T₁) ≤ Norm(T₂) при T₂ > T₁
```
